# MobileNetV2：NB-TCM-CHM 第一轮实验

日期：2026-10-21。实验目录：`runs/mobilenet_v2_nb_tcm_chm_baseline`。

## 结果

| 数据 | 图片数 | Top-1 | Top-3 | Macro F1 |
|---|---:|---:|---:|---:|
| Dataset 1 内部测试 | 512 | 93.16%（477/512） | 98.83%（506/512） | 93.07% |
| Dataset 2 独立手机白底实拍 | 400 | **68.25%（273/400）** | 92.00%（368/400） | 66.36% |

两组都是固定最佳权重后的评估。模型根据 Dataset 1 验证集的 macro F1 选择：最佳为第 16 轮，验证 Top-1 93.20%、macro F1 92.99%。没有使用 Dataset 2 调参、早停或选择权重。它们是项目自定义分组划分的结果，不是原论文实验的精确复现。

网络图片和实拍图片的 Top-1 相差约 **24.91 个百分点**。当前主要问题是跨来源泛化，不能把内部测试的 93.16% 描述为摄像头实物识别准确率。仅凭这轮实验还不能区分背景、尺度、光照、药材批次或标注差异各自的影响。

手机实拍中，覆盆子召回率 10%（2/20）、草豆蔻 25%（5/20）、小茴香 35%（7/20），是后续重点检查的类别。高 softmax 分数也会出错，当前没有可靠的未知类别拒识能力。

## 数据处理

- 用户已准备并解压的 `assets/NB-TCM-CHM` 共 3,784 张，全部可读，没有发现完全重复图片对应冲突标签。
- Dataset 1：训练 2,357 张、验证 515 张、内部测试 512 张。Dataset 2：全部 400 张留作独立测试。
- 发现 24 个文件级重复冗余和 10 对满足保守近似规则的图片；重复与近似图片分组后再划分，同组不跨集合。本次分组没有发现需要排除的网络图与手机测试图重叠。
- 同组样本仍保留，图片数量不等于独立实物数量；保守近似规则不能发现所有同源图片。
- 显式对齐 `doukou` 与 `Amomi Fructus Rotundus`，不对两部分数据分别自动编号。
- 每张图片先 EXIF 校正、转 RGB、保比例白边填充至 320×320，再缩放到 160×160。原始图片未改写。

完整审计和逐类划分在 `data/nb_tcm_chm/audit.json`，逐图片清单在 `manifest.json`；运行目录保存了同一清单的快照和 SHA256。

## 训练与导出

- 环境：conda `common`，Python 3.11.17，PyTorch 2.11.0+cu128，RTX 4060 Laptop GPU，8 GB 显存。未安装或升级环境依赖。
- 模型：MobileNetV2，宽度 1.0，官方 ImageNet 预训练，20 分类；使用 1.0 是为了直接使用 torchvision 官方预训练权重，未声称已训练 0.75 版本。
- 训练：batch 64，两轮分类头预热，随后全网微调，共 20 轮；AdamW、标签平滑 0.05、适度仿射及颜色增强、CUDA 混合精度。
- 纯训练阶段耗时 363.70 秒，约 6.06 分钟；峰值 CUDA 已分配内存约 1,371.77 MiB。该值不包含所有驱动内存，也不是板端内存需求。
- 模型参数 2,249,492；`best.pt` 文件 9,213,835 字节。
- 已导出 `export/mobilenet_v2_fp32.pt2`（10,094,375 字节），随机输入的 CPU 原模型／重新加载计算图最大绝对误差为 0。
- 这是 FP32 电脑端导出，尚未进行 INT8 量化、E84 转换或板端运行。

## 实现检查

类别别名对齐、重复分组不跨集合、保比例白边预处理共 3 项自动检查通过。另抽查网络与手机域共 4 张原图：直接预测的输入张量与训练缓存预处理结果逐元素一致，CPU 原模型与重新加载 FP32 导出图的最大 logits 误差均为 0，记录在 `inference_checks.json`。单图预测命令已用本地枸杞子图片实测。

## 后续实验建议

先保留本轮结果作为基线。下一轮优先检查公开训练数据的实物形态覆盖与背景差异，再在开发集上比较输入分辨率、数据增强和 MobileNetV3-Small；也可验收用户已准备的 CHM-100 数据，按药材部位与炮制状态对齐后补充训练。

Dataset 2 已被用于诊断，如果下一轮专门按这些错误优化或用其中部分图片微调，就应明确它已经参与开发，另行固定独立评估方案，不能继续把本轮 400 张全部称为未参与选择的最终测试。
